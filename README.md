# 我们的海

一个支持多人共享的鱼缸网页。安装 Node.js 后运行 `npm start`，再打开 `http://localhost:3000`。

## 功能

- 点击“添加鱼苗”即可打开绘画窗口，提交次数不限。
- 提交检测后会弹出“像鱼相似度”质检结果，达到 75% 才能进入鱼缸。
- 检测通过后再取名，名字不能和已有小鱼重复。
- 鱼会在大鱼缸里游动，头上显示名字和爱心数量。
- 画鱼窗口提供多种线条和更多颜色。
- 绘画过程中可以保存私人草稿，关闭页面后仍可恢复；成功放入鱼缸后草稿会自动清除。
- 每次打开页面都会显示规则提醒，并明确说明鱼苗可在三分钟内删除。
- 新鱼会从鱼缸上方自然落入水里。
- 点击鱼缸里的鱼或排行榜里的爱心按钮可以点赞。
- 当前浏览器提交的鱼在提交后三分钟内可以删除，删除按钮会显示在鱼名和排行榜中。
- 侧边栏按爱心数量显示排行榜，只展示前 15 条。
- 通过服务器网址访问时，所有用户共享鱼、名字、爱心和排行榜数据。
- 直接打开 `index.html` 时会降级为浏览器 `localStorage` 本地模式。
- 每次打开页面会自动移除 8 个月前提交的鱼，页面打开期间也会定时检查。

## Netlify 公网部署

项目已包含 `netlify.toml`、`netlify/functions/api.js` 和 Netlify Blobs 持久化配置。通过 Netlify 部署后，所有访问者会共享鱼缸、点赞、重名校验和三分钟删除规则。

1. 将整个项目推送到 GitHub、GitLab 或 Bitbucket。
2. 在 Netlify 新建站点并导入该仓库。
3. 保持自动识别的构建命令 `npm run build:netlify` 和发布目录 `dist`，然后发布。

Netlify Drop 的拖放模式只托管静态文件，不能运行 Functions，因此把 `dist` 拖入 [Netlify Drop](https://app.netlify.com/drop) 可以获得页面预览，但不能使用多人共享鱼缸。要获得可公开共享的鱼缸网址，使用上面的 Git 导入流程，或在已登录 Netlify CLI 的环境运行 `netlify deploy --build --prod`。

## 本地运行

共享数据在本地写入 `data/fish.json`。安装 Node.js 后执行 `npm start`，再打开 `http://localhost:3000`。
